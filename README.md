# Рукописный текст пером на Ender 3 Neo

Программа превращает обычный набранный текст в G-code, который принтер
пишет **ручкой, закреплённой вместо сопла** — так, будто писали от руки.

Умеет три вещи, которых нет у готовых конвертеров:

* **свой почерк** — печатает пропись, вы вписываете туда буквы ручкой,
  фотографируете, программа находит осевую линию каждой буквы и делает из
  неё шрифт;
* **живое письмо** — несколько начертаний одной буквы, дрожание пера,
  плавающая строка, наклон, описки с зачёркиванием, кляксы;
* **печать прямо из окна** — по USB, с паузой, остановкой и калибровкой Z.

Ни одной команды нагрева в выходном файле нет и быть не может: генератор
их не выпускает, а `validate()` проверяет результат ещё раз.

---

## Запуск

### Готовый exe

`dist/handwriter.exe` — один файл, Python и библиотеки внутри, ставить
ничего не нужно. Двойной щелчок открывает окно.

Тот же файл работает и как командная строка, если запустить его с
аргументами:

```bash
dist\handwriter.exe text --text "Привет" -o out.gcode
dist\handwriter.exe selftest
```

Рядом лежит `dist/handwriter/` — та же программа папкой. Весит больше,
но **запускается за доли секунды**, тогда как одиночный exe при каждом
старте распаковывает себя во временную папку. Если пользуетесь часто —
берите папку и сделайте ярлык на `handwriter.exe` внутри неё.

Если программа не запустилась, рядом с exe появится `hw-ошибка.log`
с причиной.

### Из исходников

Нужен Python 3.10+ с Pillow, numpy, scipy, opencv и pyserial:

```bash
python -m pip install -r requirements.txt
python hw.py
```

Проверить, что всё на месте:

```bash
python hw.py selftest
python tests/run_all.py
```

### Пересобрать exe

```bash
python build_exe.py --both
```

Сборка идёт во временной папке с латинским путём: PyInstaller спотыкается
о кириллицу и пробелы в пути к проекту. Иконка рисуется на лету тем же
векторным шрифтом, что и текст, — внешних файлов не требуется.

## Перед первой печатью: механика и Z

Это самая ответственная часть. Ошибка здесь ломает перо или царапает стол.

### Держатель пера

1. Ручку крепят к каретке рядом с соплом — печатным кронштейном,
   хомутом или магнитным держателем.
2. **Держатель должен быть подпружиненным.** Жёстко закреплённое перо
   при малейшей неровности стола либо не пишет, либо продавливает бумагу.
   Пружина даёт запас хода 3–5 мм и сама компенсирует неровности.
3. Кончик пера в свободном состоянии выставьте **чуть ниже сопла**
   (на 2–4 мм). Тогда при письме пружина слегка поджата, а линия ровная.

### Парковка Z — почему по умолчанию только X и Y

У Ender 3 Neo стоит датчик CR Touch. Команда `G28` опускает голову, пока
датчик не сработает. Если перо торчит ниже сопла сильнее, чем ход пружины,
оно упрётся в стол раньше датчика и погнётся.

Поэтому по умолчанию стоит **парковка `xy`**: принтер паркует только X и Y,
а Z не трогает вовсе. Порядок работы такой:

1. Включите принтер, из меню поднимите Z так, чтобы перо висело
   примерно **2 мм над бумагой** (это и есть «подъём на холостых»).
2. Запускайте задание. В прологе стоит `G92 Z2.0` — принтер принимает
   текущую высоту за 2 мм и дальше считает Z от неё.

Если у вас надёжный подпружиненный держатель и вы уверены, что перо
переживёт промер — поставьте парковку `all`, тогда Z будет отсчитываться
от стола, как при обычной печати.

### Граница: сверить положение до печати

Кнопка **«Граница»** (на вкладках «Текст», «Рисунок», «Печать»): принтер
медленно, два круга, объезжает прямоугольник того, что будет напечатано на
текущем листе (или края листа), и стоит по полсекунды в каждом углу.
**Перо при этом не опускается ни разу** — наоборот, оно поднимается на 2 мм
выше обычной высоты холостых. Если порт не выбран, программа предложит
сохранить этот G-code в файл.

### Подбор «Z письма»

Вкладка **Печать → Лесенка Z**. Принтер нарисует ряд коротких штрихов,
опускаясь на каждом шаге ниже. Возьмите тот Z, на котором линия впервые
стала ровной и сплошной, и впишите его в поле **Z письма**.

Слишком высоко — линия рвётся. Слишком низко — перо царапает бумагу и
пружина работает на пределе.

## Размер листа: A4 не влезет

Стол Ender 3 — 220×220 мм. A4 это 210×297 мм: **297 мм не помещается ни
вдоль, ни поперёк.** Поэтому по умолчанию стоит **A5 (148×210)** — самый
большой стандартный формат, который влезает целиком.

Если нужен именно A4 — пишите на нём в два прохода, сдвигая лист и меняя
`угол листа на столе Y`. Программа заранее предупредит красной строкой на
вкладке «Лист», если лист не помещается.

## Свой почерк: полный путь

### 1. Напечатать пропись

Вкладка **Почерк → Создать шаблон…**, или:

```bash
python hw.py template -o propis/ --variants 3
```

Получите `propis_01.png`, `propis_02.png`, …, общий `propis.pdf` и
`propis_spec.json`. Последний файл **обязательно сохраните** — он говорит
программе, где какая буква на листе.

Печатайте **без масштабирования** (в диалоге печати «100 %», «реальный
размер», не «вписать в страницу»). Масштаб роли не играет для
распознавания, но перекос — играет.

### 2. Написать буквы

В каждой ячейке напечатаны четыре направляющие: верхняя пунктирная —
линия заглавных, средняя пунктирная — высота строчных, **сплошная —
базовая линия**, нижняя пунктирная — для выносных элементов (у, р, д, ц).

Пишите **тёмной ручкой**: гелевой, роллером, линером; обычная синяя
шариковая тоже подходит — программа смотрит на самый тёмный цветовой
канал, и синие чернила для неё такие же густые, как чёрные. Направляющие
напечатаны светло-серым специально — программа отсекает всё, что светлее
порога, и оставляет только вашу ручку. Карандашом писать не надо: он
слишком светлый и уйдёт вместе с разлиновкой.

Каждая буква встречается три раза (или сколько вы задали) — **пишите её
каждый раз чуть по-разному**. Именно эти отличия потом и создают
ощущение живого текста.

### 3. Сфотографировать

Сверху, лист целиком, все четыре чёрных квадрата по углам в кадре.
Свет ровный, без бликов и без тени от телефона. Небольшой наклон камеры
программа исправит сама — она находит реперы и выпрямляет лист. Слегка
выгнутую бумагу (до 3 мм) тоже: после выпрямления по реперам каждая
ячейка ещё раз подгоняется по своей напечатанной рамке.

Пятый маленький квадрат под левым верхним нужен, чтобы определить
ориентацию: снимок можно сделать хоть вверх ногами.

### 4. Загрузить

Вкладка **Почерк → Выбрать фото…**. Программа выпрямит лист, нарежет его
на ячейки, найдёт осевую линию каждой буквы и покажет сеткой все
начертания. Щёлкните по неудачному — оно посереет и не попадёт в шрифт.
Потом **Принять распознанное** и **Сохранить шрифт…**.

Из командной строки:

```bash
python hw.py import -s propis/propis_spec.json -p foto1.jpg foto2.jpg -o pocherk.json
```

Если букв распозналось мало — подвиньте ползунок **порог чернил**:
больше значение — программа считает чернилами более светлые пиксели.

Разлиновка, рамки и бледные образцы букв на реальной печати часто
выходят темнее задуманного, а камера телефона ещё и поднимает контраст.
Программа это учитывает: она заново рисует пустой шаблон, совмещает его
с каждой ячейкой фото и там, где шаблон что-то напечатал, считает
чернилами только то, что заметно темнее самой печати. Поэтому писать
можно прямо поверх бледного образца, а точки ставить на линию.

Галочка **вычитать разлиновку** нужна редко — только если направляющие
пропечатались слишком тёмными или вы писали на обычной тетрадной бумаге.
На штатном шаблоне она делает хуже: срезает собственные горизонтальные
штрихи букв Т, Ц, Ш, лежащие прямо на линии.

### 5. Разобрать, что получилось

Переключатель над сеткой:

* **Распознанное** — что программа только что прочитала с фото. Щелчок
  по плитке исключает её из приёмки (плитка сереет).
* **Мой шрифт** — всё, что уже лежит в вашем почерке. Щелчок помечает
  начертание красным, кнопка **Удалить отмеченные** убирает помеченные.
  Так неудачную букву можно выбросить поштучно, не стирая весь почерк.

### 6. Писать

Буквы, которых вы не оцифровали, берутся из встроенного шрифта — текст
напечатается в любом случае. Если снять галочку **встроенный шрифт для
недостающих букв**, на их месте останется пустое место той же ширины —
так сразу видно, чего в почерке не хватает.

Текст из Word и из браузера можно вставлять как есть: «ё» и «й»,
записанные двумя кодами, знаки ударения, мягкие переносы и невидимые
пробелы программа приводит в порядок сама.

Программа запоминает, какой почерк и какой профиль вы открывали
последними, и подхватывает их при следующем запуске (файл
`hw-настройки.json` рядом с программой). В строке состояния будет
написано, что именно восстановлено.

## Эксперимент: почерк со свободного листа

Пропись не обязательна. Напишите от руки что угодно на любом листе —
белом, в клетку, в линейку, — сфотографируйте и откройте
**Почерк → 4. Эксперимент → Почерк со свободного листа…**

1. **Открыть фото…** — программа уберёт клетку/линейку и найдёт строки.
2. Слева впишите, **что написано на листе, строка в строку** (переносы —
   как на фото) и нажмите **Разложить текст по строкам фото**. Если строк
   в тексте меньше, чем на листе, берутся первые сверху.
3. Программа найдёт в каждой строке базовую линию, высоту строчных,
   наклон письма, разделит строку на слова и слова на буквы: раздельные
   буквы — по просветам, слитное письмо — по самым тонким местам вдоль
   наклона.
4. Проверьте каждую строку (◀ ▶). Мышью тянутся **красные** линии
   (границы букв), **зелёные** (края слов), **синяя** (базовая линия) и
   **голубая** (высота строчных); наклон можно вписать числом. Внизу
   сразу видно, какие буквы получились; щелчок по букве — не брать её.
5. **Передать буквы в «Распознанное»**, дальше как с прописью:
   **Принять распознанное** и **Сохранить шрифт…**.

Лучше всего получаются раздельные буквы или аккуратная пропись, 5–10
строк, ровный свет, фото сверху. У слитного письма границы между буквами
неоднозначны, поэтому их почти всегда стоит поправить руками.

Буквы сохраняют ваш естественный наклон: если текст выходит слишком
косым, уменьшите **наклон** на вкладке «Реализм».

```bash
python hw.py freehand -p лист.jpg -t что_написано.txt -o pocherk.json
```

## Эксперимент: соединения букв

Галочка **соединять буквы** (Почерк → 4. Эксперимент): буквы внутри слова
соединяются плавной линией, как в слитном письме, и перо между ними
по возможности не отрывается. Цифры и знаки не соединяются.
**Дальность** — дальше какого расстояния (в долях высоты заглавной)
соединение не рисуется.

У каждого начертания есть **вход** (сюда приходит линия от предыдущей
буквы) и **выход** (отсюда уходит к следующей). Программа ставит их сама,
а у букв со свободного листа они стоят там, где буквы были соединены на
фото. В **Редакторе соединений…** их можно переставить щелчком по линии
буквы (правая кнопка — другая точка) и для каждой буквы выбрать
«с буквой слева / справа: авто / соединять / не соединять». Внизу —
проба на любом слове. Настройки хранятся в файле шрифта, поэтому после
правок шрифт нужно сохранить.

Из командной строки: `python hw.py text ... --joins`.

## Таблицы и формулы

**Таблица** — строки, начинающиеся с `|` (как в Markdown). Строку-разделитель
`|---|---|` под шапкой можно писать, можно нет. Таблицу из Excel или Word
можно просто вставить: две и больше строки с ячейками через табуляцию тоже
становятся таблицей.

```
| t, с | h(t) |
|---|---|
| 0,4 | 5,06 |
| ∞ | 8 |
```

Рамка рисуется пером, линии чуть «гуляют», как от руки. Ширина столбцов —
по содержимому; если таблица шире полей, длинный текст в ячейках
переносится. В тетради в клетку ряд занимает две клетки, а черты идут по
линиям клетки. Кнопка **Таблица** над полем текста вставляет заготовку.

**Формула** — LaTeX между знаками `$`: `$\frac{8}{\sqrt{1+0,16\omega^2}}$`.
`$$…$$` — формула отдельной строкой по центру. Дроби пишутся в два этажа,
корень — с чертой над подкоренным, скобки `\left( \right)` растягиваются,
у `\sum`, `\lim` — пределы сверху и снизу. Знаки формул берутся из вашего
почерка, если они в нём есть. Строка с высокой формулой раздвигает соседние,
в клетке — на целые клетки. Кнопка **Формула** оборачивает выделенное в `$…$`.

Работает: `^ _ {} \frac \dfrac \sqrt \sqrt[3] \left \right \text \mathrm
\overline \vec \hat \dot`, греческие `\alpha … \omega`, `\cdot \times \pm \le
\ge \ne \approx \to \infty \partial \int \sum \prod \lim`, функции `\sin \cos
\tg \arctg \lg \ln \exp` и пробелы `\, \; \quad`. Незнакомая команда
пишется своим именем. Знаки ω, φ, √, ∞, Δ, ², ₁ есть и в самом шрифте —
их можно вставлять прямо текстом.

## Окно

* **Ctrl+C / Ctrl+V / Ctrl+X / Ctrl+A / Ctrl+Z / Ctrl+Y** работают в любой
  раскладке, в том числе в русской; по правой кнопке мыши — меню
  «Вырезать / Копировать / Вставить / Выделить всё».
* **F5** — обновить превью, **Ctrl+S** — сохранить G-code.
* **тёмная тема** — галочка в правом нижнем углу. Выбор запоминается;
  при первом запуске тема берётся из настроек Windows.

## Настройки

### Лист

| Настройка | Что делает |
|---|---|
| формат, ширина, высота | размер бумаги в мм |
| поля | отступы от краёв листа до текста |
| угол листа на столе X / Y | где лежит левый нижний угол бумаги |
| поворот листа на столе | **любой угол 0–360°**; 90° — альбомная. Как лёг лист, видно на схеме «Стол принтера сверху»: красная черта — верх листа |
| высота заглавной | размер шрифта; рукописный обычно 5–7 мм |
| межстрочный | в долях от высоты буквы |
| выравнивание | влево / по центру / вправо / по ширине |
| красная строка | отступ первой строки абзаца (только влево и по ширине) |
| отбивка между абзацами | доп. просвет между абзацами, мм |
| разлиновка | нарисовать линии тетради вместе с текстом |
| **поворот текста** | любой угол 0–360°, против часовой, вокруг центра полей |
| ужать повёрнутый текст в поля | под углом строка вылезает за поля — весь текст пропорционально уменьшается, программа пишет, до скольких процентов |
| подбирать размер автоматически | уменьшить шрифт, чтобы всё влезло на лист |
| если не влезает | `pages` — на несколько листов, `shrink` — уменьшить, `clip` — обрезать |

Если автоподбор не справился даже при минимальном размере, программа
скажет об этом прямо, а не выдаст молча двадцать страниц.

#### Тетрадь в клетку

Галочка **писать по клеткам** на вкладке «Лист». Межстрочный интервал
становится ровно шагом клетки, и каждая строка садится на свою линию —
на каждом листе, начиная с первой строки.

| Настройка | Что делает |
|---|---|
| размер клетки | обычно 5 мм |
| первая строка от верха | от верхнего края листа до линии, на которой стоят буквы первой строки |
| строка через клеток | 1 — писать в каждой строке, 2 — через одну |
| высота букв | высота заглавной в долях шага строк; 0,8 при клетке 5 мм — это 4 мм |

Размер шрифта, межстрочный и автоподбор в этом режиме подбираются сами,
отбивка между абзацами округляется до целых строк, текст под рисунком тоже
начинается с линии. В превью видна клетка (в G-code её, конечно, нет).

Кнопка **Метки строк** рисует у левого и правого поля короткие чёрточки на
высоте каждой будущей строки. Если все метки сдвинуты от линий одинаково —
поправьте «первую строку от верха» (или «угол листа на столе Y»); если
расхождение растёт к низу листа — «размер клетки».

### Реализм

Готовые наборы: **Аккуратно · Обычно · Небрежно · Второпях ·
Каллиграфия · Каллиграфия, острое перо**.
Дальше всё настраивается по отдельности:

| Настройка | Что делает |
|---|---|
| смешивать варианты | как часто брать разные начертания одной буквы |
| смещение / разброс размера / разброс поворота | разнобой букв |
| наклон и разброс наклона | общий курсив и его нестабильность |
| **дрожание пера** | неровность линии. Рабочий диапазон **0.005–0.045**; выше 0.06 буквы разваливаются |
| длина волны дрожания | около 1.0 — волна размером в букву, это и выглядит как рука |
| волна базовой линии, снос строки | строка «плывёт» |
| разброс пробелов, съезжание к концу строки | неровные интервалы |
| **доля зачёркнутых слов** | слово пишется, черкается и пишется заново |
| **доля описок** | зачёркнутая копия написана с ошибкой (соседняя клавиша, перестановка, удвоение, пропуск) |
| как зачёркивать | `line` — черта, `zigzag` — зигзаг, `scribble` — каракули |
| доля клякс | мелкая обводка на месте буквы |
| доля непрописанных штрихов | перо «не взяло» отдельный штрих |
| нажим | лёгкое покачивание Z — линия становится неравномерной по толщине |

Текст остаётся читаемым: описка всегда идёт в паре с зачёркиванием и
правильной копией, а не портит содержание.

**Зерно случайности**: 0 — каждый раз по-новому, любое другое число —
результат воспроизводится в точности.

#### Каллиграфия

У шарикового стержня линия всегда одной толщины, поэтому толстые и тонкие
линии программа набирает из нескольких проходов пера рядом с собой —
туда-обратно, не отрывая пера от бумаги.

| Настройка | Что делает |
|---|---|
| перо | **широкое** — как плакатное: штрих поперёк пера широкий, вдоль — волосяной. **острое** — как в прописях: нажим (утолщение) на штрихах вниз, вверх — волосяная |
| ширина пера / нажим | наибольшая толщина линии, мм. Для букв 6 мм хорошо 0,8–1,2 |
| угол широкого пера | классика — 30–45° к строке |
| толщина стержня | чем тоньше стержень, тем больше проходов и плотнее линия; от неё же толщина линии в превью |

Писать дольше примерно в три раза.

#### Каллиграфический почерк (пропись)

Кнопка **«Каллиграфический почерк (пропись) — включить всё»** на вкладке
«Реализм» (или «Каллиграфический (пропись)» на вкладке «Почерк») включает
встроенный шрифт-пропись, острое перо с нажимом и подходящий размер.

Шрифт сделан из страницы дореволюционной азбуки (общественное достояние):
каждая буква вырезана и векторизована по осевой линии, у «д» два начертания,
как в образце. Й, Ё собраны из И/Е с дужкой и точками. Заглавных Ъ, Ы, Ь,
латиницы и знаков препинания в образце нет — они берутся из встроенного
шрифта. В прописи строчные в 2,4 раза ниже заглавных, поэтому кнопка
поднимает высоту заглавной до 8 мм, а в режиме клетки — до 1,3 строки.

Шрифт пересобирается командой `python tools/make_callig_font.py --preview`
(разметка букв — в самом скрипте, образец — `tools/azbuka.png`).
Из командной строки: `--font callig`.

Ползунки везде можно не только тянуть: рядом поле, куда вписывается точное
число (например, угол 123.5).

### Перо и станок

| Настройка | Что делает |
|---|---|
| Z письма | высота, на которой перо касается бумаги |
| подъём на холостых | насколько поднять перо **над бумагой** при переездах: оно едет на «Z письма» + это. Меньше 0,5 мм программа не ставит — перо зацепит лист |
| малый подъём + порог | тоже над бумагой: между близкими штрихами перо поднимается не на всю высоту — экономит время |
| Z после парковки | при парковке `all`: на этой высоте перо едет к первой букве и опускается уже на месте |
| подачи | скорость письма, холостых и по Z |
| перо на сервоприводе | подъём сервой вместо Z; **на Neo этот порт занят CR Touch** |
| парковка | `xy` (безопасно), `all`, `none` |
| карта стола | `m420` — применить сохранённую, `g29` — промерить заново |
| разрешить Z ниже нуля | `M211 S0`; нужно, если перо оказалось выше сопла |

### Рисунок

Вкладка **Рисунок**. Три источника, их можно сочетать:

* **Картинка** (PNG, JPG, BMP, GIF, TIFF, WebP) — превращается в линии;
* **SVG** — линии берутся как есть: `path` (все команды, включая дуги),
  `line`, `polyline`, `polygon`, `rect`, `circle`, `ellipse`, `use`,
  с учётом `transform`; скрытое (`display:none`) пропускается;
* **эскиз мышью** — рисуйте прямо на листе справа: перо, линия,
  прямоугольник, эллипс, ластик. **Shift** — ровно (линия через 15°,
  квадрат, круг), **Ctrl+Z** — отменить. Эскиз можно сохранить в файл и
  загрузить; при следующем запуске он и открытая картинка восстанавливаются.

**Двигать, увеличивать, крутить.** Инструмент **«двигать»**: щёлкните по
линии эскиза или по картинке (Shift — добавить к выделению) или обведите
рамкой. Тяните за середину — сдвиг, за угол — размер, за кружок сверху —
поворот (Shift — по 15°). Колесо мыши — крупнее/мельче, стрелки — сдвиг на
1 мм (Shift — 5 мм), Delete — удалить, Ctrl+A — всё, Ctrl+C/Ctrl+V — копия.
Кнопки «Отразить ↔», «масштаб, %» и «повернуть, °» — для точных значений.
Всё отменяется Ctrl+Z. Картинка из файла двигается так же, а поля
«Размещение картинки» обновляются сами.

**С текстом**: *только рисунок* (текст не пишется), *сверху, текст под
ним* (картинка в верхней половине полей, текст начинается под ней),
*поверх текста* (на листе с заданным номером).

| Картинка → линии | Для чего |
|---|---|
| контур | обводка тёмных областей: логотипы, силуэты, иконки |
| осевая линия | линейные рисунки, раскраски, подписи — одна линия на штрих, а не двойной контур |
| края (фото) | контуры предметов на фотографии |
| штриховка | тон штриховкой: 1–4 направления, чем темнее, тем гуще. Шаг и угол задаются на бумаге |
| контур + штриховка | вместе |

Порог тёмного, инверсия, автоконтраст, размытие, детальность — подготовка
картинки. Размещение: ширина/высота (0 и 0 — вписать в поля), привязка к
краю, сдвиг, поворот, отражение. Перо: обводить несколько раз (гуще линия),
скорость в % от подачи письма, дрожание руки, упорядочивание штрихов
(меньше холостых), склейка близких штрихов без подъёма пера.

## Командная строка

```bash
# текст в gcode
python hw.py text -i письмо.txt -o письмо.gcode \
    --sheet A5 --size-mm 6 --preset Обычно --font pocherk.json --svg превью.svg

# уместить любой ценой на одну страницу
python hw.py text -i письмо.txt -o out.gcode --autofit

# пропись для сбора почерка
python hw.py template -o propis/ --variants 3 --latin

# фото прописи -> шрифт
python hw.py import -s propis/propis_spec.json -p foto*.jpg -o pocherk.json

# тетрадь в клетку 5 мм, первая строка в 20 мм от верха листа
python hw.py text -i письмо.txt -o out.gcode --grid --grid-cell 5 --grid-first 20

# повернуть текст на 15 градусов
python hw.py text -i письмо.txt -o out.gcode --text-angle 15

# картинка или SVG в gcode рисунка
python hw.py draw -i кот.png -o кот.gcode --mode hatch --width 100 --png кот.png
python hw.py draw -i логотип.svg -o лого.gcode --width 60 --anchor top

# лесенка Z для подбора высоты пера
python hw.py calib -o calib.gcode

# порты и отправка на принтер
python hw.py ports
python hw.py send -i письмо.gcode --port COM5
```

## Как устроено

```
hw/
  core/
    font_vector.py  встроенный однолинейный шрифт: 166 глифов,
                    русский, украинский, латиница, цифры, знаки.
                    Глифы записаны путями в стиле SVG — их легко править
    glyphset.py     глиф = штрихи + ширина; у символа несколько вариантов;
                    приведение к единицам шрифта, упрощение, порядок штрихов
    vectorize.py    фото -> осевые линии: выравнивание света, бинаризация,
                    скелет Zhang–Suen, трассировка графа, обрезка усов,
                    отдельная обработка точек (ё, й, i)
    sheet.py        пропись и обратное чтение: реперы, гомография,
                    нарезка на ячейки с известной базовой линией
    humanize.py     дрожание, наклон, разнобой, описки, зачёркивания,
                    каллиграфия (широкое и острое перо)
    drawing.py      рисунки: картинка -> контур / осевая / края / штриховка,
                    разбор SVG, размещение на листе, порядок штрихов, эскиз
    layout.py       перенос, выравнивание, абзацы, автоподбор, страницы
    gcode.py        Marlin: перо через Z, безопасный пролог, проверка границ
    preview.py      SVG и растровое превью
    printer.py      USB: построчно с ожиданием ok, пауза, стоп, лесенка Z
    config.py       все настройки, профили в JSON
  gui/app.py        окно, шесть вкладок
  cli.py            командная строка
```

Единицы шрифта: базовая линия 0, высота заглавной 14, строчных 9,
выносные до −4, диакритика до 18. «Размер 6 мм» означает высоту
заглавной буквы 6 мм.

## Что стоит знать

* **A4 на стол 220×220 не помещается** — см. выше.
* **Порт сервопривода на Neo занят CR Touch.** Подъём пера сервой
  потребует свободного пина; по умолчанию перо поднимается осью Z.
* **Скорость.** Страница A5 мелким текстом — 15–40 минут. Ось Z у Ender
  небыстрая, а перо поднимается на каждом штрихе. Помогают: больший
  «порог малого подъёма», меньший «подъём на холостых», выше подача по Z.
* **Бумагу надо прижать** — малярным скотчем или магнитами. Сдвиг листа
  посреди задания исправить нельзя.
* **Первый запуск делайте над бумагой, а не над стеклом**, и держите руку
  у выключателя.
